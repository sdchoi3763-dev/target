# TARGET LAB

정보통신설비 유지보수·관리 및 성능점검 웹앱 (GitHub Pages 배포용)

## 배포
1. 이 폴더의 파일 전부를 저장소 맨 위(루트)에 올립니다.
2. Settings › Pages › Build and deployment › Source: **Deploy from a branch**, Branch: **main / (root)** › Save
3. 1~3분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 업데이트
`index.html`과 `sw.js`를 새 파일로 바꿔 올리면 됩니다. 사용자는 앱을 한 번 다시 열면 새 버전을 받습니다.

## 데이터
입력한 데이터는 각 사용자 기기의 브라우저 안에만 저장됩니다(서버로 전송되지 않음).
기기를 바꾸거나 다른 사람과 옮길 때는 앱의 백업 내보내기/가져오기를 사용하세요.
